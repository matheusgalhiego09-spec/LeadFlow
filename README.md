
# LeadFlow

### Plataforma de Prospecção Comercial

O LeadFlow é uma aplicação web desenvolvida para facilitar a identificação de potenciais clientes e apoiar processos de prospecção comercial.

O projeto utiliza dados geográficos e integração com a API Geoapify para permitir pesquisas de estabelecimentos por localização e segmento de atuação.

## Funcionalidades

- Pesquisa de estabelecimentos comerciais por localização
- Filtragem por categorias de negócios
- Integração com a API Geoapify
- Visualização de informações dos estabelecimentos
- Interface responsiva para diferentes dispositivos

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Geoapify API
- Netlify
- Git e GitHub

## Objetivo do projeto

Desenvolver uma ferramenta que facilite a busca por oportunidades comerciais, reunindo informações úteis para prospecção em uma interface simples e acessível.

O projeto também permitiu aplicar conhecimentos de desenvolvimento front-end, consumo de APIs e publicação de aplicações web.
